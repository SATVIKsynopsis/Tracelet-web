---

```text
Usage: otel-test [OPTIONS] <COMMAND>

Commands:
  init
  test
  validate
  help      Print this message or the help of the given subcommand(s)

Options:
  -f, --file <FILE>    [default: otel-test.yaml]
      --color <COLOR>  [default: auto] [possible values: auto, always, never]
  -h, --help           Print help
  -V, --version        Print version
```

| Command | What it does |
| --- | --- |
| [`otel-test init`](/docs/cli/init) | Writes the starter project: a config, a test file and three fixtures |
| [`otel-test test`](/docs/cli/test) | Runs the tests and exits non-zero on failure |
| [`otel-test validate`](/docs/cli/validate) | Checks everything and shows the rewritten config, without running tests |

See [CLI flags](/docs/cli/flags) for every option and environment variable, and [Exit codes](/docs/cli/exit-codes)
for what each code means.

Every command first prints the version banner (`otel-test v0.1.0`). Errors are printed to stderr, prefixed with
`error:`.
